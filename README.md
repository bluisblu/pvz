# Plants vs. Zombies (0.9.9) Decompilation

A very messy incomplete decompilation of Plants vs. Zombies.

## Contributing

1. Copy `PlantsVsZombies.exe` and `PlantsVsZombies.pdb` to `orig/BETA_099`
2. Run `python configure.py`
3. Run `ninja`

After that, you should have MSVC 8.0 automatically installed and the project configured. You can use [objdiff](https://github.com/encounter/objdiff) to open the cloned folder containing `objdiff.json`.
